# QurbaniHat - Livestock Booking Platform

## Purpose
A modern web marketplace where users can browse cows and goats for Qurbani, view details, and place a booking after logging in. Built for the Software Engineering course assignment (Category A8-Pineapple).

## Live URL
(https://qurbani-hat-ebon-six.vercel.app/)

## Key Features
- Home page with featured animals, Qurbani tips, and top breeds
- All Animals page with sort by price
- Animal Details page with a booking form
- Login and Register with Email/Password and Google (Firebase Authentication)
- My Profile page showing the logged-in user's name, photo, and email
- Update Information page to edit name and photo
- Toast notifications for actions like login, logout, and booking
- Custom 404 (Not Found) page
- Fully responsive layout for mobile, tablet, and desktop

## npm Packages Used
- next, react, react-dom - core framework
- firebase - authentication (Email/Password and Google sign-in)
- react-toastify - toast notifications
- react-icons - icons used across the app
- tailwindcss - styling
